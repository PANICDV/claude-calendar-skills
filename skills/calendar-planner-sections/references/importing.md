# Importing calendars by section

Golden rule: **each file goes into its own new calendar, never into the main one.** That
way, updating a section means deleting that calendar and creating it again, without touching
anything else. Deleting the main calendar erases all of the person's events.

In the delivery include only the section for the app the person uses (default: Google),
written as short steps.

## Google Calendar (on the web, from a computer; the phone app cannot import)

**First time (done only once):**
1. Create one calendar per section: at calendar.google.com, the "+" button next to "Other
   calendars" → "Create new calendar" → the exact name from the legend (with emoji) →
   Create calendar. Repeat for each section.
2. Import: "+" → "Import" → select the file (for example `1_thesis.ics`) → under "Add to
   calendar" choose the matching calendar → Import. Repeat with each file.
3. Color: hover over each calendar in the left column → ⋮ → pick the legend color. For the
   exact shade, click "+" and paste the hex.

**Update a section:** ⚙️ Settings → choose that section's calendar → "Remove calendar" →
Delete. Create it again with the same name, import the new file and give it its color. The
other sections are not touched.

**Hide or show a section:** click the calendar's checkbox in the left column.

**If something was imported into the main calendar by mistake:** there is no bulk undo.
Recurring events are deleted by opening one → Delete → "All events". The rest, by searching
for the emoji and deleting from the results.

## Apple Calendar (Mac)
File → Import → choose the .ics → "New Calendar". Apple usually takes the color the file
carries; if not, right-click → Get Info → color. Repeat with each file. To delete:
right-click the calendar → Delete.

## Outlook (web)
Create one calendar per section ("Add calendar" → "Create blank calendar", where you also
pick the color). Then "Add calendar" → "Upload from file" → choose the .ics and its target
calendar. To delete: right-click the calendar → Delete.
