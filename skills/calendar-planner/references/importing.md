# Importing and deleting calendars

Golden rule: **always import into a new calendar, never into the main one.** That way,
updating the plan means deleting that calendar and importing again, without touching the
person's own events. Deleting the main calendar erases all of the person's events.

In the delivery include only the section for the app the person uses (if unknown, Google),
written as short steps.

## Google Calendar (on the web, from a computer; the phone app cannot import)
**Create the calendar:** at calendar.google.com, the "+" button next to "Other calendars" →
"Create new calendar" → name (for example "October plan" or "🔔 Reminders") → Create calendar.

**Import:** "+" next to "Other calendars" → "Import" → select the .ics → under
"Add to calendar" choose the calendar you just created → Import.

**Color:** hover over the calendar in the left column → ⋮ → pick a color.

**Delete an old plan:** ⚙️ Settings → under "Settings for my calendars", choose the
calendar → at the bottom, "Remove calendar" → Delete.

**If it was imported into the main calendar by mistake:** there is no bulk undo. Recurring
events are deleted by opening one → Delete → "All events". The rest, by searching for the
emoji and deleting from the results.

Google ignores any per-event colors in the .ics: the color comes from the calendar.

## Apple Calendar (Mac)
File → Import → choose the .ics → in the dialog, choose "New Calendar". To delete it:
right-click the calendar → Delete. On iPhone, open the .ics from Files or from an email and
tap "Add All".

## Outlook (web)
Calendar → "Add calendar" → "Upload from file" → choose the .ics and the target calendar
(create a new one first under "Add calendar" → "Create blank calendar").
To delete it: right-click the calendar → Delete.
